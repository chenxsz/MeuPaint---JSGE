# Paint Simples

Paint simples desenvolvido em Java utilizando JSGE.

## Sobre o projeto

O projeto consiste em um Paint básico para criação e edição de desenhos.
Foi desenvolvido com o objetivo de praticar conceitos de programação em Java
na disciplina de Estrutura de Dados.

## Funcionalidades

- Linha
- Retângulo
- Elipse
- Polígono
- Caneta
- Borracha
- Desfazer (Undo - ctrl + z)
- Refazer (Redo - ctrl + y)
- Alteração da cor do contorno
- Alteração da cor do preenchimento

## Tecnologias

- Java
- Java Swing (JFrame)
- JSGE
